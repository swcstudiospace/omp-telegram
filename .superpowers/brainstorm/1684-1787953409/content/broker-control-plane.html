Chosen Design: Broker Control Plane

Reply-only targeting in Telegram, with the broker as the single authority for routing, capture, and audit.

End-to-End Flow
OMP Session Side
Session starts
Registers with local broker
Publishes heartbeat + completion event
Exposes terminal capture handle
Accepts routed OMP commands
Broker Side
Tracks live session roster
Captures terminal screenshot at completion
Builds Telegram post payload
Stores message-to-session bindings
Parses reply commands and audits them
Telegram Side
Channel post with completion screenshot
Operators reply with `/goal`, `/advisor`, `/exec`, `/stop`
Reply always targets the bound session post
Audit + Safety
Allowed Telegram users only
Recognized OMP command set
Guarded shell subcommands
Command result ack back to Telegram

What This Means

The extension remains lightweight inside OMP, while the broker owns Telegram integration, session bindings, terminal screenshot capture, and command dispatch. That gives you one bot, one control surface, and clean multi-session behavior without turning Telegram into a raw terminal.
